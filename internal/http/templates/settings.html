Settings

Match sensitivity controls how strictly the server matches faces. Recognition compares the face in a photo against every enrolled face using cosine similarity — a value between 0 and 1, where 1 is a perfect match. A face is considered a match when its best similarity score is at or above the threshold below.

A lower threshold is more lenient: more matches, but a higher chance of false positives. A higher threshold is stricter: fewer matches, but fewer false positives. The default is 0.45.
